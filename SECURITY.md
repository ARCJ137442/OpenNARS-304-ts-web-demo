# Security Policy

## Reporting a vulnerability

This repository contains a static Astro site and browser Workers. Please do not publish unpatched security details in a public issue. Report vulnerabilities through the [OpenNARS-304-ts Security Advisories](https://github.com/ARCJ137442/OpenNARS-304-ts/security/advisories/new), including the affected commit or release, reproduction steps, impact, and a proposed mitigation.

The Demo Lab has no project backend. Reports should still distinguish browser-side issues, generated Pages assets, Worker isolation, and the source build pipeline. Do not submit secrets, private data, or exploit payloads in public issues.

## Scope

The source Demo repository, its build scripts, generated browser Workers, and the public Pages deployment are in scope. Third-party browsers, GitHub infrastructure, and upstream OpenNARS/ONA/Jev components should be reported to their respective maintainers.
