- Chrome `154.0.8037.93`，Node `v22.17.0`
- Core 构建绑定：`631e29c`
- Demo 构建绑定：`30b3fee`
- 页面：`/opennars-304-ts-lab/microworld.html`

## 解释边界

示例知识模式仍未达到持续 20 TPS；空白探索接近目标但没有自主 NARS 操作，不能替代具身场景的性能门。概念增长与长尾推理延迟仍是主要瓶颈。本次只是当前版本复测，不能被解释为性能优化或收敛证据。
