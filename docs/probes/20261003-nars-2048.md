# NARS × 2048：规则、交互与动效验收（2026-10-04）

本 Demo 参考用户本地 `H:\A137442\Develop\AI\Jev\jev-2048` 的公开玩法与交互经验，但没有复制 Jev 的云端 API、密钥、模型协议或服务端代码。项目保留独立 TypeScript 引擎，Jev MIT attribution 见 `COPYING-JEV-2048-MIT.txt`。

## 已实现

- 纯 TypeScript 4×4 引擎：四方向压实、每回合单次合并、得分、新块、终局判定、确定性 seed。
- NARS 接入：局面空格/最高块/边缘分数感知、复合目标、合并/移动反馈；Worker 的 NARS 记忆跨棋盘重开保留，`记忆`按钮才重建 Worker。
- Canvas 棋盘渲染器：参考 Jev 的统一坐标系，避免 DOM 方块与粒子坐标漂移；空格、数字色阶、方块入场、合并脉冲、高值发光、方向粒子、得分反馈与终局反馈均基于真实 move 结果。
- 键盘方向键与触摸滑动共用 `applyMove`，无效方向会显示短暂震动反馈；`prefers-reduced-motion` 关闭动画但保留棋盘状态和记录。
- 经验观察、FPS/TPS/RPS、操作来源、NAR 时间、匿名 JSON 实验记录导出与中英许可入口已接入统一 Lab 页面。

## 语义边界

棋盘重开只替换游戏状态并递增局数；NARS Worker 与 NAR 时间保持。重置记忆才终止并重建 Worker。页面刷新会自然创建新 Worker。导出的记录只含 seed、局面、分数、局数、记录文本和时间，不含密钥或外部服务数据。
