## 已读源码与结论

- 参考 `src/client/engine.ts` 是纯函数式移动：克隆棋盘后按方向逐行/列压实与合并，保留 tile id 做动画；`validMoves()` 会试算四向，不能让试算修改入参。它支持矩形棋盘、生成值上下限、均匀/加权分布、终局判断与得分。
