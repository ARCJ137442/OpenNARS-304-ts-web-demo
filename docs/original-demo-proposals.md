# 原创 Demo 提案

本批次的四个指定 demo 负责覆盖棋盘、多操作射击、空间操作和飞行控制。为了让 Demo Lab 不止是旧案例的陈列，另保留四个原创方向。

## Echo Relay 回声信标

部分可观测迷宫。探测脉冲逐格传播，撞墙后返回回声。动作是转向、发射、移动；感知是回声方向、强度分桶、已知墙面和当前位置。目标可以是 Narsese 复合属性 signal_at_beacon。

可证伪实验：固定迷宫种子，对比有回声反馈和无反馈的 30 次运行。若到达率没有稳定提升，不能宣称 NARS 学会了探索。

## Tidal Commons 潮汐阀门

两个蓄水池、闸门和周期潮汐组成一个有延迟反馈的控制系统。动作是开关闸、等待、切换水路；感知是水位桶、潮汐方向和溢出风险。它可以检验 NARS 是否能从三步延迟后果中保留目标。

## Split-Signal Workshop 双信道修理站

颜色信号与真实故障类型不是一一对应，玩家要先检查、再拿零件、再修理。真值只留在环境诊断中，不进入 Narsese，避免答案泄漏。它适合展示感知分类与多步操作之间的关系。

## Wayfinding Window 迁徙窗口

小型动态网格、有限电量和周期性天气窗口。动作包括移动、等待和标记路径；感知包括邻格、天气阶段、电量桶和目的地相对方向。它检验目标保持、风险权衡和环境变化下的适应。

当前批次已将 Echo Relay 定为原创实现对象，因为它与已有追逐、平衡、搬运、射击重叠最少，且能直接验证复合目标与操作结果反馈是否支持探索。Tidal Commons、Split-Signal Workshop、Wayfinding Window 留待后续；所有原创 demo 都必须先有纯模型合同测试，再加入共享 Worker 和浏览器工作台。
